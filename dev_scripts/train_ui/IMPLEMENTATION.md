# TOSA RAIL station map — implementation spec (assets ↔ C)

Approved design: `DESIGN.md` (round 2, "use your suggestions"). Assets are generated by
`export_station_map.py` from `network.json`. Never hand-edit the outputs: change `network.json`
(or the generator) and rerun it (`PYTHON=<python with Pillow> ./build_all.sh`, or just the exporter).
The exporter validates station ids and count against `include/constants/train_stations.h` and the names
against `src/data/train_stations.h`. Adding a real station = add it there, add it to `network.json`, and rerun.

The exporter fails (non-zero exit) if a tilemap cell would hold both label and tube pixels, if two edges
share a cell that is not a station's centre cell, if a node or waypoint is off a cell centre (8k+4) or a run
isn't 0/45/90°, if the diagram needs more than 512 tiles, or if the header/tray rows aren't fully opaque.
As a self-check it rebuilds frames purely from the exported files: `out/export_check_{west,east,north}_3x.png`.

## Runtime palette rules (BG2 cells)
- An edge is grey: set all its `sTrainMapEdgeCells` entries to pal 3 if either end isn't accessible
  (state != OPEN). Otherwise keep the default (its line palette).
- A label: pal 3 if not accessible, pal 4 if selected, else pal 0 (`sTrainMapLabelCells`).
- A station's centre cell can appear in two edges' lists (WEST = cell 1540 now). It is always fully covered by
  the node OBJ, so whichever palette is written last doesn't show.

## OBJ placement (camera = camX, camY; viewport = screen y 16–127)
- Node: frame `(interchange ? 2 : 0) + (accessible ? 0 : 1)` at `(x - 8 - camX, y - 8 - camY + 16)`.
- Gold ring: frame 4 at the same position as the selected node (hidden while it travels, see timings).
  Denied ring: frame 5 on the target station.
- Head: `(x - 8 - camX, y - 22 - camY + 16)` on the current station.
- Pill: `labelW / 8` pieces at `(labelX + 8*i - camX, labelY - camY + 16)`, i = 0 → frame 0, last → frame 2,
  others frame 1; priority 2. `labelY` is the label's text cell top (small font): caps sit at labelY+4..+11,
  and the pill art covers labelY+1..+14.
- Legend tubes: frame i at `(sTrainMapLegendX[i], TRAIN_MAP_LEGEND_Y = 4)`, priority 0.
- Tray pictogram: `tray_line` frame = the station's line index, or `TRAIN_MAP_LINE_COUNT` for an interchange,
  at **(5, 131)**, priority 0. Art covers x 6–20, y 134–144. Hide it while a tray message is shown.

## Camera (dead zone + re-centre)
- Canvas 512x256, viewport 240x112 → `camX ∈ [0, 272]`, `camY ∈ [0, 144]`.
- Station viewport position `sx = x - camX`, `sy = y - camY`. **Inside the dead zone if `48 ≤ sx ≤ 192` and
  `24 ≤ sy ≤ 80`** (48 px from each side, 24 from the top, 32 from the bottom for the label).
- When the selected station is outside it after a move: target = `(clamp(x - 120, 0, 272), clamp(y - 56, 0, 144))`,
  eased over **16 frames, quadratic ease-out**: `cam = from + (to - from) * (1 - (1 - t/16)^2)`, t = 1..16.
- On open: the camera snaps (no ease) to that target for the initial cursor station.

## Cursor picking (cone rule)
- Candidates for D-pad direction d: every station T ≠ cursor that is accessible (state OPEN) and isn't the
  player's current station. With `(dx, dy) = T - cursor`, take `(along, across)` = right `(dx, dy)`,
  left `(-dx, dy)`, down `(dy, dx)`, up `(-dy, dx)`. T is in the cone if `along > 0 && |across| <= along`
  (a 90° cone).
- `score = along + |across| + (lineMask(T) & lineMask(cursor) ? 0 : 64)`. Lowest score wins; ties go to the lower id.
- No candidate: if a non-accessible station lies in the cone (same test), run the **denied** feedback on the
  lowest-scoring one. Otherwise do nothing.
- Initial cursor on open: the accessible station (not the current one) nearest the current station
  (`|dx| + |dy|`, same-line bonus as above).

## Timings (GBA frames)
- **Ring travel:** 8 frames, quadratic ease-out between node centres. The pill is hidden while travelling.
  When the ring arrives, the pill and the tray text update. The camera ease (16 f) starts on the same frame
  as the ring.
- **Denied:** ring x offset per frame `+2,+2,0,-2,-2,0,+2,+2,0,-2,-2,0` (12 f). The grey ring (nodes frame 5)
  on the target is visible while `((t / 4) & 1) == 0`, for t = 0..35. Play `SE_FAILURE` at t = 0. The tray
  message "You haven't been to {NAME} yet.\nVisit it on foot first." stays until the next input.
- **Chevrons:** +1 px outward while `(frameCounter / 16) & 1` (right +x, left −x, down +y, up −y).
- **Grid drift:** +1 every 4 frames on both axes (down-right), added on top of the camera.

## Chevrons (cell rule, as the exporter's check renders it)
Visible cells: columns `c0 = camX / 8 .. c1 = (camX + 239) / 8`, rows `r0 = camY / 8 .. r1 = (camY + 111) / 8`.
For each edge and each side: take the edge's cells on the last visible column/row of that side (right `c == c1`,
left `c == c0`, down `r == r1`, up `r == r0`, inside the other range) whose neighbour just outside (`c+1`,
`c-1`, `r+1`, `r-1`) is also a cell of that edge. If there are any, place **one** chevron at the middle one:
`cy = r*8 + 4 - camY + 16`, `cx = c*8 + 4 - camX`.
- right: frame 0 at `(226, cy - 8)`; left: frame 0 hflip at `(-2, cy - 8)`
- down: frame 1 at `(cx - 8, 113)`; up: frame 1 vflip at `(cx - 8, 14)`
- Art bounds inside a frame: right/left x 5–10, y 4–12; down/up x 4–12, y 5–10. Clamp `cy` to 24..119 and
  `cx` to 8..231 so the art stays inside the viewport. Priority 1.

## Deviations from the requested format
1. **`chevron.png` is 16x(16·2), not 8x(8·2).** The approved Gen 3 chevron is 6x9 and doesn't fit an 8x8 OBJ.
   Both frames use the 16x16 shape (4 tiles each); art bounds are listed above.
2. **Two OBJ palettes.** The UI sprites (ink, panel greys, 3 gold, 2 red) plus a 3-colour ramp per line don't fit
   in 15 colours. `obj.pal` → nodes, chevron, pill; `obj_lines.pal` → legend, tray_line.
3. **Tray interchange frame** = ringed node with no tube stub; the tray's line-name text names both lines.
4. **PNG padding:** `diagram.png` / `frame.png` are padded to whole 16-tile rows with blank tiles after the last
   used tile. The maps only reference used tiles.
5. **Grid tile 0 isn't blank** (it's the grid's top-left tile). BG3 is fully covered, so this is harmless.
6. Station centre cells may appear in two edges' cell lists (see the runtime palette rules).
