Select an area on the right, then drag on the map to paint its cells. Right-drag erases, Alt-click picks the area under the cursor. Station tool drops/moves an area's station marker; Line tool extends the line selected in the Rail tab. Each cell is one region-map cursor square (28 × 15 grid). Use the Maps tab to choose which game maps belong to which area.
Select a line, then use the Line tool: click stations in order, click empty cells for bends, right-click to undo a point.
